## 🌟 What is Solana Time Machine?

A retro arcade game built on Solana that pays players **real SOL tokens** for every successful hit in a classic Pong-style game. Experience the world's first Play-to-Earn retro arcade using Solana's lightning-fast transactions.

## ✨ Features

- **Real Solana Rewards**: Every hit in the game earns you 0.000001 SOL instantly
- **Phantom Wallet Integration**: Connect your Phantom wallet to start earning
- **Retro Arcade Aesthetics**: Neon glow effects, aurora backgrounds, and pixel-perfect UI
- **Ultra-Fast Transactions**: Solana confirms transactions in ~400ms
- **Zero Gas Fees**: Near-zero cost transactions on Solana devnet
- **Mobile & Desktop Responsive**: Works seamlessly across devices

## 🛠️ Tech Stack

- **Frontend**: Next.js 14, React 18, TypeScript
- **Styling**: Tailwind CSS with custom neon theme
- **Blockchain**: @solana/web3.js for blockchain interactions
- **Game Engine**: p5.js for WebGL canvas rendering
- **Wallet**: Phantom Browser Extension
- **Deployment**: Vercel

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/your-username/solana-time-machine.git
cd solana-time-machine

# Install dependencies
npm install
# or
yarn install

# Run development server
npm run dev
# or
yarn dev

# Open http://localhost:3000
```

## 🎯 How to Play

1. **Connect Phantom Wallet**: Click "Connect Phantom Wallet" and approve the connection
2. **Move Your Paddle**: Drag your mouse/tilt device to control the paddle
3. **Hit the Ball**: Each successful hit earns you 0.000001 SOL
4. **Track Your Progress**: View real-time score and SOL balance
5. **Reset**: Click "Reset Game" to start over
